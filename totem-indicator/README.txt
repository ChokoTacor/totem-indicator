TOTEM INDICATOR (Fabric 1.21.11, клиентский мод)

Что делает:
  - Infinity = зелёный, Stinger = красный, Eternity = фиолетовый
  - тотемы в хотбаре, во второй руке, в инвентаре и любых сундуках обведены цветной рамкой (без заливки)
  - слева сверху список: сколько каких тотемов у вас есть
  - если у другого игрока в руке такой тотем, рядом с ником появляется цветная метка [Infinity] / [Stinger] / [Eternity]
    (только когда игрок в прямой видимости, сквозь стены не работает)

Сборка:
  Вариант А (Gradle установлен или IntelliJ IDEA):
    1. Откройте папку проекта в IntelliJ IDEA (JDK 21) и дождитесь импорта Gradle,
       либо в терминале в этой папке:  gradle build
    2. Готовый мод: build/libs/totem-indicator-1.0.0.jar
  Вариант Б (надёжнее всего):
    1. На https://fabricmc.net/develop создайте шаблон: Minecraft 1.21.11, Yarn,
       Mod ID: totemindicator, Package: com.totemindicator, БЕЗ галочки Split sources
    2. В шаблоне удалите папку src и скопируйте вместо неё папку src из этого проекта
    3. Соберите:  gradlew build  ->  build/libs/...jar (файл без -sources)

Сборка без установки программ (через GitHub):
  1. Зарегистрируйтесь на github.com и создайте новый репозиторий (New repository).
  2. Распакуйте архив. В репозитории: Add file -> Upload files, перетащите ВСЁ содержимое
     папки totem-indicator (вместе с папкой .github) и нажмите Commit changes.
  3. Откройте вкладку Actions, дождитесь зелёной галочки (3-5 минут).
     Если сборка не запустилась сама: Actions -> build -> Run workflow.
  4. Откройте завершённый запуск, внизу в Artifacts скачайте totem-indicator.
     Внутри будет jar: берите тот, что БЕЗ -sources в названии.
  5. Положите jar в папку mods вместе с Fabric API.
  Если запуск красный - откройте его, скопируйте текст ошибки и отправьте разработчику.

Установка: положите .jar в папку mods вместе с Fabric API 0.141.5+1.21.11.

Если тотемы не подсвечиваются:
  Возьмите тотем в руку и введите команду  /totemdebug  - она покажет точное название
  предмета на сервере. Нужное слово добавьте в список ключевых слов в TotemType.java.
